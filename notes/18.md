# 世界模型（空间智能流派）学习路线

> 目标：以获取人工智能硕士学位为导向，系统掌握世界模型-空间智能流派的知识体系。
> 核心人物与机构：李飞飞 (Fei-Fei Li) / World Labs、Yann LeCun / AMI Labs

---

## 零、理解这个方向：什么是「空间智能」与「世界模型」？

在开始学习之前，先建立全局认知：

### 空间智能 (Spatial Intelligence)

空间智能是李飞飞提出的 AI 下一个前沿。核心理念是：**语言让机器能够谈论世界，空间智能让机器能够理解、想象、推理并与物理世界互动。** 它关注的是 AI 对三维空间的理解、操作和生成能力，是连接「语言智能」与「物理世界」的桥梁。

### 世界模型 (World Model)

借用李飞飞 2026 年发布的 **《A Functional Taxonomy of World Models》** ，世界模型按功能分为三类：

| 类型 | 输出 | 核心承诺 | 典型代表 |
|------|------|---------|---------|
| **渲染器 (Renderer)** | 观测（像素/图像） | 视觉保真度 | Sora, Genie 3, World Labs RTFM |
| **模拟器 (Simulator)** | 状态（几何/物理/动态） | 结构准确性 | World Labs Marble, NVIDIA Omniverse |
| **规划器 (Planner)** | 行动（动作序列） | 决策正确性 | VLA 模型, World Action Model |

**三个模型的底层知识是共通的**——几何、物理、动态规律。真正的前沿是让一个统一模型同时具备渲染、模拟和规划能力。

### 技术基础循环 (POMDP)

```
智能体 → 行动 → 世界状态 → 观测 → 智能体 → …
```

所有世界模型都是这个循环在不同维度上的投影。理解这个循环是理解整个领域的钥匙。

## 一、前置基础（0-3 个月）

> 如果没有 CS/数学本科背景，需要先补齐这些。

### 1.1 数学基础

| 领域         | 核心内容                  | 推荐资源                                                      |
| ---------- | --------------------- | --------------------------------------------------------- |
| **线性代数**   | 矩阵运算、特征值分解、SVD、射影几何基础 | Gilbert Strang《Introduction to Linear Algebra》+ MIT 18.06 |
| **概率论与统计** | 贝叶斯推断、高斯分布、马尔可夫过程、信息论 | 《概率导论》(Bertsekas)                                         |
| **微积分**    | 多元微积分、梯度、链式法则         | 3Blue1Brown 微积分系列                                         |
| **最优化**    | 梯度下降、Adam、凸优化基础       | Boyd《Convex Optimization》前 4 章                            |
| **几何学基础**  | 刚体变换、旋转矩阵、四元数、李代数入门   | 《Multiple View Geometry in Computer Vision》附录             |

### 1.2 编程与工具

| 技能 | 要求 | 方式 |
|------|------|------|
| **Python** | 熟练使用 NumPy, PyTorch, JAX | 复现经典论文，PyTorch 官方教程 |
| **Linux/命令行** | 日常工作环境 | 装一台 Linux 桌面或 WSL2 |
| **Git** | 版本控制 | GitHub 日常使用 |
| **CUDA 基础** | 理解 GPU 编程模型 | CUDA 官方入门 |
| **可视化** | Matplotlib, Open3D, Polyscope | 边学边用 |

### 1.3 机器学习基础

| 阶段 | 内容 | 资源 |
|------|------|------|
| 经典 ML | 回归、分类、聚类、SVM、决策树、集成学习 | 吴恩达 Coursera ML 课程 / 李航《统计学习方法》 |
| 深度学习基础 | MLP、CNN、RNN、Transformer、注意力机制 | 李沐《动手学深度学习》(d2l.ai) |
| 深度学习进阶 | BatchNorm、Dropout、ResNet、ViT、损失函数设计 | d2l.ai + 相关论文 |

> **里程碑 1**：能用 PyTorch 从零实现一个 ViT 并在 CIFAR-100 上训练。

## 二、计算机视觉核心（2-4 个月）

> 空间智能的根基在 3D 视觉。这一步不能跳过。

### 2.1 2D 视觉基础

| 主题 | 关键概念 | 推荐资源 |
|------|---------|---------|
| 图像处理基础 | 卷积、边缘检测、滤波、特征提取 | Szeliski《Computer Vision: Algorithms and Applications》1-5 章 |
| 目标检测 | R-CNN 系列, YOLO, DETR | 相关论文 + MMDetection 实践 |
| 语义/实例分割 | FCN, U-Net, Mask R-CNN, SAM | MMSegmentation |
| 自监督学习 | SimCLR, MoCo, MAE, DINO | 论文精读 |

### 2.2 多视角几何（关键！）

> 这是空间智能区别于普通 CV 的核心基础。

| 主题 | 内容 | 资源 |
|------|------|------|
| 相机模型 | 针孔相机、内参/外参、畸变 | MVG 第 6 章 |
| 对极几何 | 本质矩阵、基础矩阵、三角化 | MVG 第 9-12 章 |
| 运动恢复结构 (SfM) | COLMAP 原理 | MVG 第 18 章 + COLMAP 论文 |
| 多视角立体 (MVS) | 深度图估计、点云融合 | MVG 第 13 章 |

- 核心教材：**Hartley & Zisserman《Multiple View Geometry in Computer Vision》**（必读）
- 实践：用 COLMAP 对自己拍摄的场景做三维重建

### 2.3 三维表示与深度学习

| 表示形式 | 典型方法 | 特点 |
|---------|---------|------|
| 点云 (Point Cloud) | PointNet, PointNet++, Point Transformer | 稀疏、原始传感器输出 |
| 体素 (Voxel) | VoxNet, 3D CNN | 规则网格、内存消耗大 |
| 网格 (Mesh) | Pixel2Mesh, Mesh R-CNN | 紧致、适合渲染 |
| 隐式表示 | DeepSDF, Occupancy Networks, **NeRF** | 连续、高分辨率 |
| 显式基元 | **3D Gaussian Splatting (3DGS)** | 实时渲染、可编辑 |

> **里程碑 2**：能复现 PointNet++ 做点云分类/分割 + 理解 NeRF 原理并跑通代码。

## 三、空间智能核心：NeRF 与 3DGS 时代（2-3 个月）

> 这是当前空间智能流派最活跃、最核心的技术栈。

### 3.1 NeRF 及演进（必读论文链）

```
NeRF (ECCV 2020)                          ← 原论文，开创性工作
├── Mip-NeRF (ICCV 2021)                  ← 抗锯齿
├── Instant-NGP (SIGGRAPH 2022)           ← 5 秒训练
├── TensoRF (ECCV 2022)                   ← 张量分解加速
├── Block-NeRF (CVPR 2022)                ← 城市场景
├── NeRF in the Wild (CVPR 2021)          ← 无约束照片
├── DreamFusion (ICLR 2023)               ← 文字→3D（SDS 蒸馏）
└── Zip-NeRF (ICCV 2023)                  ← 最新整合方案
```

**学习方式**：每篇论文读完 → 看代码 → 跑通 demo → 写笔记总结核心贡献与局限。

### 3.2 3D Gaussian Splatting 及演进

```
3DGS (SIGGRAPH 2023)                      ← 原论文，实时渲染里程碑
├── Scaffold-GS (CVPR 2024)               ← 结构化高斯
├── 4DGS (CVPR 2024)                      ← 动态场景
├── SuGaR (CVPR 2024)                     ← 提取 mesh
├── GaussianOpacity Fields (arXiv 2024)   ← 辐射场统一
├── PixelSplat (CVPR 2024)                ← 稀疏视图重建
├── MVSplat (ECCV 2024)                   ← 高效多视图
└── InstantSplat (ECCV 2024)              ← 无优化 3DGS
```

### 3.3 生成式 3D / 4D 内容

| 方向 | 代表工作 | 核心思路 |
|------|---------|---------|
| 文字→3D | DreamFusion, MVDream, Zero123 | SDS 蒸馏 + 多视图扩散 |
| 图像→3D | LRM, Instant3D, CRM | 前馈大模型直接回归 |
| 视频→4D | Animate3D, 4D-fy, DreamGaussian4D | 动态高斯表示 |
| 场景生成 | Text2Room, SceneDreamer, LucidDreamer | 3D 场景级生成 |

> **里程碑 3**：能完整讲解 NeRF 到 3DGS 的技术演进路线，并复现至少一个 3DGS 论文。

## 五、前沿方向与硕士选题（持续跟进）

### 5.1 统一世界模型

当前最重要的趋势：**渲染、模拟、规划三类模型正在融合**。World Labs 的 Marble 平台已经能从同一个模型输出 Gaussian Splats（渲染）和碰撞网格（模拟）。

关键开放问题：
- 如何在同一架构中平衡视觉美感与物理精度？
- 如何低成本获取带几何/物理标注的三维数据？
- Sim-to-Real Gap 如何系统性地弥合？

### 5.2 候选硕士研究方向

| 方向 | 具体选题示例 |
|------|------------|
| **高效 3D 表示** | 稀疏 Gaussian 表示、混合 NeRF+3DGS 架构 |
| **世界模型预训练** | 视频预训练用于 3D 理解、跨模态知识迁移 |
| **4D 动态场景** | 动态 Gaussian Splatting、长序列 4D 重建 |
| **具身世界模型** | 面向机器人的潜空间世界模型、Sim2Real |
| **空间推理** | 3D 场景理解 + LLM、Spatial VLM |
| **模拟器生成** | 生成式模拟环境、自动场景构建 |
| **多模态融合** | LiDAR + Camera + Radar 统一世界表示 |

### 5.3 必读综述与资源

- **Awesome Spatial Intelligence**: [worldbench/awesome-spatial-intelligence](https://github.com/worldbench/awesome-spatial-intelligence) — 100+ 论文、30+ 数据集

## 十、关键提醒

1. **代码优先**：每篇论文读完要去读代码、跑代码。只看论文不写代码，掌握程度很浅。
2. **打好几何基础**：多视角几何是空间智能的独有门槛，不要跳过。MVG 是越啃越香的硬书。
3. **关注 World Labs**：李飞飞的 World Labs 是该方向的旗帜，持续追踪他们的论文、博客和技术报告（Marble 平台）。
4. **尽早开始项目**：不要等到「学完所有理论基础」才开始动手。学完基础 3D 视觉就可以开始做项目。
5. **英语能力**：顶会论文、课程都是英文的。如果英语阅读有障碍，先花时间提升。
6. **硕士申请策略**：空间智能是 2025-2026 年最热的方向之一。找对导师比选校更重要——优先选择在 NeRF/3DGS/World Model/Robotics 领域有持续产出的实验室。

> 最后：李飞飞说得好——「世界并不由词语构成」。空间智能的核心不是语言模型，而是让机器真正理解物理世界的几何、物理和动态。你的学习旅程，本质上就是在建立对这个信念的深层理解。
