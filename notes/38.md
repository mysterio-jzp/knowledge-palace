## Day 1：向量的几何意义

### 学什么

**核心概念：**
- 向量不只是数字串，它是空间中的一个箭头（或一个点）
- 向量的两种基本运算：加法（平移 + 首尾相接）、数乘（拉伸 / 压缩 / 翻转）
- 向量的模（长度）$||\mathbf{v}|| = \sqrt{v_1^2 + v_2^2 + \dots}$

**关键直觉：** $\mathbb{R}^2$ 中的向量 $(3, 2)$，想象从原点出发，向右走 3，向上走 2。所有运算都可以用这种几何方式理解。

### 看什么

🎬 3Blue1Brown《线性代数的本质》第 1 集：向量究竟是什么
📖 Strang §1.1 ~ §1.2

### 代码实践

```python
import numpy as np
import matplotlib.pyplot as plt

# === 两个向量 ===
v = np.array([3, 2])
w = np.array([1, 3])

# === 画箭头 ===
def plot_vector(ax, vec, origin=[0,0], color='b', label=''):
    ax.quiver(*origin, *vec, angles='xy', scale_units='xy', 
              scale=1, color=color, width=0.02, label=label)

fig, axes = plt.subplots(1, 3, figsize=(14, 4))

# 左：单独两个向量
plot_vector(axes[0], v, color='steelblue', label='v')
plot_vector(axes[0], w, color='coral', label='w')
axes[0].set_title('向量 v 和 w')
axes[0].legend()

# 中：加法 v+w（平行四边形法则）
plot_vector(axes[1], v, color='steelblue', label='v')
plot_vector(axes[1], w, color='coral', label='w')
plot_vector(axes[1], v + w, color='darkgreen', label='v+w')
axes[1].set_title('v + w (平行四边形法则)')
axes[1].legend()

# 右：数乘 0.5v, 2v, -v
for scale, c, lbl in [(0.5, 'lightblue', '0.5v'), (2, 'darkblue', '2v'), (-1, 'red', '-v')]:
    plot_vector(axes[2], scale * v, color=c, label=lbl)
axes[2].set_title('数乘：缩放与翻转')
axes[2].legend()

for ax in axes:
    ax.set_xlim(-4, 6); ax.set_ylim(-4, 6)
    ax.axhline(y=0, color='gray', lw=0.5)
    ax.axvline(x=0, color='gray', lw=0.5)
    ax.set_aspect('equal'); ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Day 2：向量的内积与投影

### 学什么

**核心概念：**
- 内积（点积）$\mathbf{v}\cdot\mathbf{w} = v_1w_1 + v_2w_2 + \dots$
- 几何意义：$\mathbf{v}\cdot\mathbf{w} = ||\mathbf{v}||\cdot||\mathbf{w}||\cdot\cos\theta$
- 内积 = 0 → 两向量正交（垂直）
- 投影：把 $\mathbf{v}$ 投到 $\mathbf{w}$ 方向上的影子

**关键直觉：** 内积衡量"两个向量有多对齐"。在 ML 中，内积就是注意力机制 $\text{softmax}(QK^T)$ 的底层运算。

### 代码实践

```python
v = np.array([3, 0])
w = np.array([1, 2])

# 内积
dot = np.dot(v, w)  # = 3*1 + 0*2 = 3

# 夹角的余弦
cos_theta = dot / (np.linalg.norm(v) * np.linalg.norm(w))
theta = np.arccos(cos_theta)  # 弧度
print(f"内积: {dot}, 夹角: {np.degrees(theta):.1f}°")

# v 在 w 上的投影
proj = (dot / np.dot(w, w)) * w
print(f"v 在 w 上的投影向量: {proj}")

# 画图
fig, ax = plt.subplots(figsize=(6,6))
ax.quiver(0,0,*v, angles='xy',scale_units='xy',scale=1,color='steelblue',label='v')
ax.quiver(0,0,*w, angles='xy',scale_units='xy',scale=1,color='coral',label='w')
ax.quiver(0,0,*proj,angles='xy',scale_units='xy',scale=1,color='darkgreen',label='投影')
# 虚线垂线
ax.plot([v[0], proj[0]], [v[1], proj[1]], 'k--', lw=0.8)
ax.set_xlim(-0.5, 4); ax.set_ylim(-0.5, 3.5)
ax.set_aspect('equal'); ax.grid(True, alpha=0.3); ax.legend()
plt.show()
```

### 在 ML 中怎么用

两个向量的内积就是它们在特征空间中的"相似度"。余弦相似度 = 归一化后的内积，是推荐系统、语义搜索的基础。

## Day 3：线性组合与张成空间

### 学什么

**核心概念：**
- 线性组合：$\mathbf{w} = a\mathbf{v}_1 + b\mathbf{v}_2$，$a,b$ 遍历所有实数
- 张成空间 (span)：所有线性组合构成的集合
- $\mathbb{R}^2$ 中：两个不共线的向量张成整个平面；两个共线的向量只张成一条线

**关键直觉：** span 就是"用这几个向量作为基础砖块，能搭出多大空间"。这直接影响——数据矩阵的 features 能表示多少信息。

### 代码实践

```python
v1 = np.array([2, 0.5])
v2 = np.array([0.5, 1.5])

fig, ax = plt.subplots(figsize=(7, 7))
# 画张成空间（密集采样）
for a in np.linspace(-3, 3, 30):
    for b in np.linspace(-3, 3, 30):
        p = a*v1 + b*v2
        ax.scatter(p[0], p[1], s=0.5, c='royalblue', alpha=0.15)

ax.quiver(0,0,*v1, angles='xy',scale_units='xy',scale=1,color='red',width=0.015)
ax.quiver(0,0,*v2, angles='xy',scale_units='xy',scale=1,color='darkgreen',width=0.015)
ax.text(*v1, 'v1', fontsize=12, color='red')
ax.text(*v2, 'v2', fontsize=12, color='darkgreen')
ax.set_xlim(-8,8); ax.set_ylim(-8,8)
ax.set_aspect('equal'); ax.grid(True,alpha=0.2)
ax.set_title('v1 和 v2 张成的空间 = 整个平面')
plt.show()
```

### 与线性相关的联系（为 Day 4 铺垫）

思考：如果 $\mathbf{v}_2 = 2\mathbf{v}_1$（比如 $\mathbf{v}_1=(1,1),\ \mathbf{v}_2=(2,2)$），张成的是什么？只张成一条线！这就是**线性相关**的几何版本。

## Day 4：线性相关 vs 线性无关（重点）

### 学什么

**核心概念（严格定义）：**

设向量组 $\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_m$（共 $m$ 个向量，每个都取自 $\mathbb{R}^n$）**线性相关**的充要条件：
> 存在不全为零的标量 $c_1, c_2, \dots, c_m$ 使得 $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_m\mathbf{v}_m = \mathbf{0}$

否则线性无关。

> ⚠️ **最容易踩的坑：** 定义里"向量的个数 $m$" 与"向量所在空间的维数 $n$" 是两回事，别因为都写成 n 就混为一谈。
> - 标量的个数 = 被检验的**向量个数 $m$**（不是维数 $n$）。例如 $\mathbb{R}^3$ 里取 5 个向量，照样只看"是否存在 5 个不全为零的标量"使线性组合为 $\mathbf{0}$，跟"3 维"无直接关系。
> - 定义本身**不依赖维数**，$\mathbb{R}^n$ 这个前提不是定义的一部分。
>
> **与维数 $n$ 强相关的关键结论（判断时的"隐藏前提"）：**
> | 在 $\mathbb{R}^n$ 中 | 结论 |
> |---|---|
> | 向量个数 $m > n$ | **必然线性相关**（定理，不用算） |
> | 向量个数 $m = n$ | 线性相关 ⇔ 矩阵行列式为 0（奇异 / 不满秩） |
> | 向量个数 $m < n$ | 可能无关也可能相关（如 $\mathbb{R}^3$ 中两个共线向量仍相关） |
>
> 第一条正是 Day 5「$\mathbb{R}^n$ 需要恰好 $n$ 个向量才能做基」和 Day 7「秩」的底层逻辑。

**等价直觉：**
- 线性相关 = 至少有一个向量是其余向量的线性组合（"多余的砖"）
- 线性无关 = 每个向量都给空间增加一个"新方向"

**结合诊断测试题 2：** $\mathbf{v}_1=(1,2,3)$，$\mathbf{v}_2=(2,4,6)$，$\mathbf{v}_3=(1,0,1)$
- $\mathbf{v}_2 = 2\mathbf{v}_1$，取 $c_1 = -2, c_2 = 1, c_3 = 0$ （不全为零），满足 $-2\mathbf{v}_1 + 1\mathbf{v}_2 + 0\mathbf{v}_3 = \mathbf{0}$
- 所以向量组线性相关 ✅

### 代码实践

```python
def check_independence(vectors, tol=1e-10):
    """通过解齐次方程组判断线性相关性"""
    A = np.column_stack(vectors)
    # 解 Ac = 0
    # 如果零空间非平凡（有非零解），则线性相关
    _, s, _ = np.linalg.svd(A)
    rank = np.sum(s > tol)
    is_independent = (rank == len(vectors))
    print(f"向量组:\n{A}")
    print(f"秩 = {rank}, 向量数 = {len(vectors)}")
    print("→ 线性无关" if is_independent else "→ 线性相关")
    return is_independent

# 测试题2的数据
v1 = np.array([1,2,3])
v2 = np.array([2,4,6])
v3 = np.array([1,0,1])
check_independence([v1, v3])        # v1,v3 → 无关
check_independence([v1, v2, v3])    # 三个一起 → 相关
```

## Day 5：基与维数、子空间

### 学什么

**核心概念：**
- **基**：一组能张成整个空间且线性无关的向量。$\mathbb{R}^n$ 需要恰好 n 个向量。
- **维数**：基中的向量个数
- **子空间**：大空间里满足「含零、加法封闭、数乘封闭」的子集
- 判定子空间的三条：① 零向量在不在？② 任意两个相加还在不在？③ 任意数乘还在不在？

**结合诊断测试题 8：** $S = \{(x,y,z) \mid x+y+z=0\}$
- ① $\mathbf{0}=(0,0,0)$ 满足 $0+0+0=0$ ✅
- ② 若 $\mathbf{u},\mathbf{v}\in S$，则 $u_1+u_2+u_3=0,\ v_1+v_2+v_3=0$，相加得 $(u_1+v_1)+(u_2+v_2)+(u_3+v_3)=0+0=0$ ✅
- ③ 若 $\mathbf{u}\in S$，则 $cu_1+cu_2+cu_3 = c(u_1+u_2+u_3) = c\cdot 0 = 0$ ✅
- 所以 S 是子空间，它的几何意义是穿过原点的一个平面。维数是 2。

### 代码实践

```python
# 验证子空间：取 S = { (x,y,z) | x+y+z=0 } 中的两个向量
u = np.array([1, -1, 0])    # 1 + (-1) + 0 = 0
v = np.array([2, 0, -2])    # 2 + 0 + (-2) = 0

print("u + v =", u+v, "sum =", (u+v).sum())  # 和是否还在 S 中
print("3*u =", 3*u, "sum =", (3*u).sum())    # 数乘是否还在 S 中

# 找 S 的一组基：两个线性无关的向量即可
# 任取 S 中两个不共线的向量
b1 = np.array([1, -1, 0])
b2 = np.array([1, 0, -1])
print("\nS 的基：")
print(f"b1 = {b1}")
print(f"b2 = {b2}")
print(f"S 的维数 = 2 (是 R³ 中的一张平面)")
```

## Day 6：矩阵作为线性变换（⭐ 本周核心）

### 学什么

**核心思想：** 矩阵不是方方的数字表格——它是**对空间的一套操作**。

$$
\begin{pmatrix} a & b \\ c & d \end{pmatrix} 
\begin{pmatrix} x \\ y \end{pmatrix} 
= x\begin{pmatrix} a \\ c \end{pmatrix} + y\begin{pmatrix} b \\ d \end{pmatrix}
$$

乘法的含义：**原来的基向量 $(1,0)$ 和 $(0,1)$ 被映射到了矩阵的两列。**

**常见变换的矩阵形式：**

| 变换 | 矩阵 | 效果 |
|---|---|---|
| 拉伸 | $\begin{pmatrix} k & 0 \\ 0 & k \end{pmatrix}$ | 均匀缩放 |
| 水平拉伸 | $\begin{pmatrix} k & 0 \\ 0 & 1 \end{pmatrix}$ | 只拉 x 方向 |
| 旋转 θ | $\begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$ | 逆时针旋转 |
| 剪切 | $\begin{pmatrix} 1 & k \\ 0 & 1 \end{pmatrix}$ | 平行四边形变形 |

### 🎬 必看

3Blue1Brown 第 3 集：矩阵与线性变换。**这集看完，矩阵的全部直觉就立住了。**

### 代码实践

```python
def apply_matrix_to_grid(A, ax, title=''):
    """把矩阵 A 作用在单位方格网上，可视化变换"""
    # 原始网格点
    points = []
    for x in np.linspace(-2, 2, 9):
        for y in np.linspace(-2, 2, 9):
            points.append([x, y])
    points = np.array(points).T  # 2 x N
    transformed = A @ points
    
    ax.scatter(points[0], points[1], s=5, c='gray', alpha=0.5, label='原空间')
    ax.scatter(transformed[0], transformed[1], s=5, c='red', alpha=0.5, label='变换后')
    
    # 画基向量的变换
    for orig, color in [([1,0],'steelblue'), ([0,1],'coral')]:
        t = A @ np.array(orig)
        ax.quiver(0,0,*t, angles='xy',scale_units='xy',scale=1,color=color,width=0.02)
    ax.set_xlim(-6,6); ax.set_ylim(-6,6)
    ax.set_aspect('equal'); ax.grid(True,alpha=0.3); ax.legend(fontsize=8)
    ax.set_title(title)

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
apply_matrix_to_grid(np.array([[2,0],[0,1]]), axes[0], '水平拉伸')
apply_matrix_to_grid(np.array([[0,-1],[1,0]]), axes[1], '旋转 90°')
apply_matrix_to_grid(np.array([[1,1],[0,1]]), axes[2], '剪切')
plt.tight_layout()
plt.show()
```

## Day 7：矩阵的秩（承上启下）

### 学什么

**核心定义：**
- **列秩** = 矩阵列向量中线性无关的个数
- **行秩** = 矩阵行向量中线性无关的个数
- 一个重要定理：行秩 = 列秩，我们统称**秩**

**几何意义：** 秩就是矩阵作为线性变换后，输出空间的维数。

- $\text{rank}=2$ 的 2×2 矩阵：把平面映射成平面（满秩，可逆）
- $\text{rank}=1$ 的 2×2 矩阵：把平面压成一条线（秩亏，不可逆）
- $\text{rank}=0$ 的矩阵：把所有东西压到原点（零矩阵）

**结合诊断测试题 9：** $A = \begin{pmatrix} 1&2&3 \\ 4&5&6 \end{pmatrix}$
- 两行，所以秩最大为 2
- 第二行是不是第一行的倍数？$\frac{4}{1}=4,\ \frac{5}{2}=2.5,\ \frac{6}{3}=2$，不成比例
- 两行线性无关 → $\text{rank}(A) = 2$

### 代码实践

```python
# 秩降维的视觉效果
A_full  = np.array([[2, 0], [0, 2]])    # rank=2 → 保持平面
A_rank1 = np.array([[1, 2], [2, 4]])    # rank=1 → 压成线
A_zero  = np.array([[0, 0], [0, 0]])    # rank=0 → 压成点

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
apply_matrix_to_grid(A_full,  axes[0], f'rank=2 (满秩)')
apply_matrix_to_grid(A_rank1, axes[1], f'rank=1 (降一维)')
apply_matrix_to_grid(A_zero,  axes[2], f'rank=0 (全压原点)')
plt.tight_layout()
plt.show()

# 题9 手算验证
A = np.array([[1,2,3],[4,5,6]])
print(f"题9 矩阵的秩: {np.linalg.matrix_rank(A)}")  # → 2
```
