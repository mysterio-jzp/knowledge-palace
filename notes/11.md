## 1. 背景与需求

### 1.1 业务场景

对话消息系统，需要处理区分 `sessionId`（会话级标识）和 `chatId`（单次消息标识）的消息。

### 1.2 核心需求

| 需求 | 描述 |
|------|------|
| **顺序保证** | 同一会话内的消息必须按发送顺序处理 |
| **高并发** | 支持大量并发会话同时进行（目标：1 万+） |
| **低延迟** | 消息从发送到消费的端到端延迟要求低 |
| **精准订阅** | 消费者只消费自己负责的会话消息，不消费其他会话 |
| **动态订阅** | 支持运行时动态增加/删除会话 |

### 1.3 当前问题

现有方案使用 **String Key 存储 + SCAN 全量扫描**，存在以下问题：

| 问题 | 说明 |
|------|------|
| **CPU 飙高** | SCAN 需要遍历整个 Key 空间，1 万会话时 CPU 达 80%-100% |
| **延迟高** | 全表扫描导致消息处理延迟增加 |
| **扩展性差** | 会话数增长时性能线性下降 |
| **资源浪费** | 轮询 SCAN 大量空转，消耗无谓的 CPU |

## 2. 方案选型

### 2.1 为什么选择 Redis Streams

| 对比维度       | String + SCAN（当前） | Redis Streams         |
| ---------- | ----------------- | --------------------- |
| **查找消息**   | SCAN 全 Key（O(N)）  | XREAD 指定 Stream（O(1)） |
| **消费者模型**  | 轮询 SCAN           | XREADGROUP 阻塞读        |
| **CPU 占用** | 80%-100%（1 万会话）   | 20%-35%（1 万会话）        |
| **顺序保证**   | 需业务层实现            | 天然保序                  |
| **动态订阅**   | 需业务层管理            | 消费者组自动管理              |
| **消息持久化**  | 依赖 RDB/AOF        | 依赖 RDB/AOF            |

### 2.2 Redis 版本要求

| Redis 版本 | Streams 支持 | 推荐程度 |
|-----------|-------------|---------|
| < 5.0 | ❌ 不支持 | 不推荐 |
| 5.0.x ~ 7.2.x | ✅ 基础支持 | 可用 |
| 8.4.x | ✅ 完整支持 | 推荐 |
| **8.6.x** | ✅ 完整支持 + 幂等生产 | **强烈推荐** |

**Redis 8.6 新增特性**：
- **幂等生产（Idempotent Production）**：解决消息重复问题
- **性能优化**：XADD 吞吐量提升，内存占用降低
- **XCFGSET 命令**：可配置幂等参数

## 4. 架构设计

### 4.1 整体架构

```

│                 Redis Streams 整体架构                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│  ┌─────────────────────────────────────────────────────────┐   │

│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐   │

│  │  ├── Consumer A (节点1) ──→ session:001, session:004    │   │
│  │  ├── Consumer B (节点2) ──→ session:002, session:005    │   │
│  │  └── Consumer C (节点3) ──→ session:003, session:006    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  消费者（业务服务）                                              │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  XREADGROUP GROUP dialogue_group consumer_{node}        │   │
│  │              STREAMS session:{session_id} >              │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 数据模型

| 概念 | Redis 实现 | 说明 |
|------|-----------|------|
| **会话通道** | Stream Key: `session:{sessionId}` | 每个会话一个独立 Stream |
| **消息** | Stream Entry | 包含 chatId、content、timestamp 等字段 |
| **消费者组** | `XGROUP CREATE` | 管理多个消费者实例 |
| **消费者** | 自动分配 | 每个服务节点是一个消费者 |

## 5. 代码实现

### 5.1 完整 Python 实现

```python
"""
Redis Streams 会话消息队列

依赖安装：
    pip install redis>=4.2.0

使用示例：
    # 生产者
    queue = RedisStreamsSessionQueue(redis_client)
    await queue.send_message("session_001", "chat_001", "hello")

    # 消费者
    queue.start_consuming(handle_message)
"""

import asyncio
import json
import logging
import socket
import time
from typing import Dict, Callable, Optional, List, Any
from dataclasses import dataclass

import redis.asyncio as redis
from redis.exceptions import ResponseError

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


@dataclass
class Message:
    """消息对象"""
    msg_id: str
    chat_id: str
    content: str
    timestamp: int
    session_id: str = ""


class RedisStreamsSessionQueue:
    """
    基于 Redis Streams 的会话消息队列
    
    核心特性：
    - 每个 Session 一个独立 Stream
    - 消费者组自动负载均衡
    - 阻塞读取，无消息时不消耗 CPU
    - 支持断点续传（Offset 管理）
    
    使用方式：
        1. 创建实例：queue = RedisStreamsSessionQueue(redis_client)
        2. 发送消息：await queue.send_message("session_001", "chat_001", "hello")
        3. 启动消费：await queue.start_consuming(handler)
        4. 停止消费：await queue.stop_consuming()
    """
    
    def __init__(self, redis_client: redis.Redis,
                 consumer_group: str = "dialogue_group",
                 consumer_name: Optional[str] = None,
                 batch_size: int = 10,
                 block_ms: int = 1000):
        """
        :param redis_client: Redis 异步客户端
        :param consumer_group: 消费者组名称
        :param consumer_name: 消费者名称（默认 hostname:pid）
        :param batch_size: 每次读取的最大消息数
        :param block_ms: 阻塞读取的超时时间（毫秒）
        """
        self.redis = redis_client
        self.consumer_group = consumer_group
        self.batch_size = batch_size
        self.block_ms = block_ms
        
        if consumer_name is None:
            import os
            self.consumer_name = f"{socket.gethostname()}:{os.getpid()}"
        else:
            self.consumer_name = consumer_name
        
        self._running = False
        self._consumer_task: Optional[asyncio.Task] = None
        self._message_handler: Optional[Callable] = None
    
    # ========== 生产者接口 ==========
    
    async def send_message(self, session_id: str, chat_id: str, content: str,
                           maxlen: int = 100) -> str:
        """
        发送消息到指定会话
        
        :param session_id: 会话 ID
        :param chat_id: 消息 ID（用于幂等）
        :param content: 消息内容
        :param maxlen: Stream 最大长度（限制内存）
        :return: 消息 ID
        """
        stream_key = f"session:{session_id}"
        message = {
            "chat_id": chat_id,
            "content": content,
            "timestamp": int(time.time() * 1000)
        }
        
        # XADD: 添加消息，限制 Stream 长度
        msg_id = await self.redis.xadd(
            stream_key,
            message,
            maxlen=maxlen,
            approximate=True
        )
        
        logger.debug(f"Message sent: session={session_id}, "
                     f"chat={chat_id}, msg_id={msg_id}")
        return msg_id
    
    async def send_batch(self, session_id: str, messages: List[Dict[str, str]],
                         maxlen: int = 100) -> List[str]:
        """
        批量发送消息到指定会话
        
        :param session_id: 会话 ID
        :param messages: 消息列表，每条包含 chat_id 和 content
        :param maxlen: Stream 最大长度
        :return: 消息 ID 列表
        """
        stream_key = f"session:{session_id}"
        msg_ids = []
        
        pipe = self.redis.pipeline()
        for msg in messages:
            data = {
                "chat_id": msg["chat_id"],
                "content": msg["content"],
                "timestamp": int(time.time() * 1000)
            }
            pipe.xadd(stream_key, data, maxlen=maxlen, approximate=True)
        
        results = await pipe.execute()
        msg_ids = [r for r in results if r]
        
        logger.debug(f"Batch sent: session={session_id}, count={len(msg_ids)}")
        return msg_ids
    
    # ========== 消费者接口 ==========
    
    async def start_consuming(self, message_handler: Callable):
        """
        启动消费者
        
        :param message_handler: 消息处理函数，签名为 handler(session_id, message_dict)
        """
        self._message_handler = message_handler
        self._running = True
        
        # 确保消费者组存在
        await self._ensure_consumer_group()
        
        # 启动消费任务
        self._consumer_task = asyncio.create_task(self._consume_loop())
        logger.info(f"Consumer started: {self.consumer_name}")
    
    async def stop_consuming(self):
        """停止消费者"""
        self._running = False
        if self._consumer_task:
            self._consumer_task.cancel()
            try:
                await self._consumer_task
            except asyncio.CancelledError:
                pass
        logger.info(f"Consumer stopped: {self.consumer_name}")
    
    async def _ensure_consumer_group(self):
        """确保消费者组存在"""
        try:
            # 尝试创建消费者组
            # MKSTREAM: 如果 Stream 不存在则自动创建
            await self.redis.xgroup_create(
                "session:*",
                self.consumer_group,
                id='$',
                mkstream=True
            )
            logger.info(f"Consumer group created: {self.consumer_group}")
        except ResponseError as e:
            # 消费者组已存在是正常情况
            if "BUSYGROUP" not in str(e):
                logger.warning(f"Consumer group error: {e}")
    
    async def _consume_loop(self):
        """消费循环"""
        while self._running:
            try:
                # XREADGROUP: 阻塞读取新消息
                result = await self.redis.xreadgroup(
                    self.consumer_group,
                    self.consumer_name,
                    {"session:*": ">"},  # '>' 表示只读新消息
                    count=self.batch_size,
                    block=self.block_ms
                )
                
                if not result:
                    continue
                
                for stream_key, messages in result:
                    stream_key = stream_key.decode() if isinstance(stream_key, bytes) else stream_key
                    session_id = stream_key.replace("session:", "")
                    
                    for msg_id, fields in messages:
                        # 处理消息
                        await self._process_message(session_id, msg_id, fields)
                        
                        # XACK: 确认消息已处理
                        await self.redis.xack(stream_key, self.consumer_group, msg_id)
                        
            except asyncio.CancelledError:
                break
            except redis.ConnectionError as e:
                logger.error(f"Redis connection error: {e}")
                await asyncio.sleep(1)
            except Exception as e:
                logger.exception(f"Unexpected error in consume loop: {e}")
                await asyncio.sleep(0.1)
    
    async def _process_message(self, session_id: str, msg_id: bytes, fields: dict):
        """处理单条消息"""
        try:
            # 解码字段
            message = {}
            for k, v in fields.items():
                key = k.decode() if isinstance(k, bytes) else k
                value = v.decode() if isinstance(v, bytes) else v
                message[key] = value
            
            logger.info(f"Processing: session={session_id}, "
                       f"chat={message.get('chat_id')}, msg_id={msg_id}")
            
            # 调用业务处理函数
            if self._message_handler:
                if asyncio.iscoroutinefunction(self._message_handler):
                    await self._message_handler(session_id, message)
                else:
                    self._message_handler(session_id, message)
                    
        except Exception as e:
            logger.exception(f"Failed to process message: session={session_id}")
            # 不 XACK，消息会被重新投递
            raise
    
    # ========== 会话管理 ==========
    
    async def get_pending_messages(self, session_id: str, count: int = 100) -> List[Dict]:
        """
        获取指定会话的待处理消息（用于断点续传）
        
        :param session_id: 会话 ID
        :param count: 获取数量
        :return: 待处理消息列表
        """
        stream_key = f"session:{session_id}"
        try:
            pending = await self.redis.xpending_range(
                stream_key, self.consumer_group, '-', '+', count
            )
            return pending
        except ResponseError:
            return []
    
    async def claim_pending_messages(self, session_id: str, 
                                     min_idle_ms: int = 60000,
                                     count: int = 100) -> List[Dict]:
        """
        认领超时的待处理消息（消费者故障恢复）
        
        :param session_id: 会话 ID
        :param min_idle_ms: 最小空闲时间（毫秒），超过此时间的消息可被认领
        :param count: 认领数量
        :return: 认领的消息列表
        """
        stream_key = f"session:{session_id}"
        
        # 获取超时的 Pending 消息
        pending = await self.get_pending_messages(session_id, count)
        
        claimed = []
        for item in pending:
            idle_ms = item.get('idle', 0)
            msg_id = item.get('message_id')
            
            if idle_ms > min_idle_ms and msg_id:
                result = await self.redis.xclaim(
                    stream_key,
                    self.consumer_group,
                    self.consumer_name,
                    min_idle_ms,
                    [msg_id]
                )
                claimed.extend(result)
        
        return claimed
    
    async def delete_session(self, session_id: str):
        """
        删除会话（会话结束时清理）
        
        :param session_id: 会话 ID
        """
        stream_key = f"session:{session_id}"
        await self.redis.delete(stream_key)
        logger.info(f"Session deleted: {session_id}")
    
    async def get_session_length(self, session_id: str) -> int:
        """获取会话的消息数量"""
        stream_key = f"session:{session_id}"
        return await self.redis.xlen(stream_key)
    
    async def get_session_info(self, session_id: str) -> Dict[str, Any]:
        """获取会话信息"""
        stream_key = f"session:{session_id}"
        try:
            info = await self.redis.xinfo_stream(stream_key)
            return {
                "length": info.get('length', 0),
                "first_entry": info.get('first-entry'),
                "last_entry": info.get('last-entry'),
                "groups": info.get('groups', 0)
            }
        except ResponseError:
            return {"length": 0, "groups": 0}
    
    async def health_check(self) -> Dict[str, Any]:
        """健康检查"""
        try:
            await self.redis.ping()
            return {
                "status": "healthy",
                "consumer_group": self.consumer_group,
                "consumer_name": self.consumer_name
            }
        except Exception as e:
            return {
                "status": "unhealthy",
                "error": str(e)
            }

        # - 通过 WebSocket 推送
        
        print(f"[业务处理] session={session_id}, "
              f"chat={chat_id}, content={content}")
        
        # 模拟业务处理时间
        await asyncio.sleep(0.01)
    
    # 4. 启动消费者
    await queue.start_consuming(handle_message)
    
    # 5. 发送测试消息
    await queue.send_message("session_001", "chat_001", "你好")
    await queue.send_message("session_001", "chat_002", "我想咨询问题")
    await queue.send_message("session_002", "chat_003", "另一个会话")
    
    # 6. 批量发送示例
    await queue.send_batch("session_003", [
        {"chat_id": "chat_004", "content": "批量消息1"},
        {"chat_id": "chat_005", "content": "批量消息2"},
    ])
    
    # 7. 保持运行
    try:
        await asyncio.sleep(60)  # 运行 60 秒
    except KeyboardInterrupt:
        pass
    finally:
        await queue.stop_consuming()
        await redis_client.close()


if __name__ == "__main__":
    asyncio.run(main())
```

### 7.3 消息确认机制

```
┌─────────────────────────────────────────────────────────────────┐
│                    消息确认流程                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 消费者读取消息（XREADGROUP）                                 │
│         │                                                      │
│         ▼                                                      │
│  2. 消息进入 Pending 列表（待确认）                              │
│         │                                                      │
│         ▼                                                      │
│  3. 业务处理完成                                                │
│         │                                                      │
│         ▼                                                      │
│  4. 发送 ACK（XACK）→ 消息从 Pending 移除                       │
│                                                                 │
│  故障恢复：                                                     │
│  - 消费者崩溃 → 消息仍在 Pending                                 │
│  - 其他消费者用 XCLAIM 认领超时消息                              │
│  - 消息不会丢失                                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

# health.py
from fastapi import FastAPI
from redis_streams import RedisStreamsSessionQueue

app = FastAPI()
queue: RedisStreamsSessionQueue = None

@app.on_event("startup")
async def startup():
    redis_client = redis.Redis(host='localhost', port=6379)
    global queue
    queue = RedisStreamsSessionQueue(redis_client)

@app.get("/health")
async def health():
    return await queue.health_check()

@app.get("/metrics/sessions")
async def get_session_metrics():
    """获取会话统计"""
    # 扫描所有 session key
    sessions = []
    async for key in queue.redis.scan_iter(match="session:*", count=100):
        length = await queue.redis.xlen(key)
        sessions.append({
            "session_id": key.decode().replace("session:", ""),
            "message_count": length
        })
    return {
        "total_sessions": len(sessions),
        "total_messages": sum(s["message_count"] for s in sessions),
        "sessions": sessions[:100]  # 限制返回数量
    }

## 9. 最佳实践总结

### 9.1 配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| `maxlen` | 100 | 限制每个 Stream 长度 |
| `block_ms` | 1000ms | XREADGROUP 阻塞时间 |
| `batch_size` | 10-100 | 每次读取消息数 |
| `appendfsync` | everysec | AOF 刷盘策略 |
| `maxmemory-policy` | allkeys-lru | 内存淘汰策略 |

### 9.2 开发规范

1. **必须 ACK**：每条消息处理完成后必须调用 `XACK`
2. **幂等处理**：使用 `chatId` 做幂等，防止重复消费
3. **超时认领**：设置合理的 `min_idle_ms`，处理消费者故障
4. **限制长度**：使用 `MAXLEN` 限制 Stream 长度，防止内存爆炸
5. **会话清理**：会话结束时调用 `delete_session()` 删除 Stream
6. **连接池**：使用连接池管理 Redis 连接

### 9.3 与旧方案对比

| 对比维度 | String + SCAN（旧） | Redis Streams（新） |
|----------|--------------------|--------------------|
| **CPU 占用** | 80%-100% | 20%-35% |
| **延迟** | 高（全表扫描） | 低（O(1) 访问） |
| **扩展性** | 差 | 好 |
| **顺序保证** | 需业务层实现 | 天然保序 |
| **消费者管理** | 需业务层实现 | 消费者组自动管理 |
| **断点续传** | 需业务层实现 | 原生支持 |
| **代码复杂度** | 高 | 低 |

### 10.1 方案优势

| 优势 | 说明 |

| **动态扩容** | 消费者数量可动态增减 |
