## 一、背景与目标

### 1.1 业务背景

在实际的 AI Agent 应用中，存在以下典型需求：

- 不同用户需要不同的能力集（会员等级、租户隔离）
- 能力需要热插拔，不能每次修改代码后重启服务
- 技能文档需要与代码分离，便于非技术人员维护
- 单个技能的说明文档（含指令、示例）可能很长，不能全部塞入系统提示

### 1.2 核心目标

设计一个**基于 Markdown 文件的动态技能加载系统**，实现：

| 目标 | 说明 |
|------|------|
| **动态发现** | 扫描目录自动加载新技能，无需重启 |
| **按需加载** | 只在需要时加载技能正文，不占用上下文 |
| **触发匹配** | 根据用户输入自动激活相关技能 |
| **配置分离** | 技能定义与代码分离，低门槛维护 |
| **可扩展** | 支持向量检索、权限控制等高级特性 |

## 二、技术选型

### 2.1 核心框架：Pydantic AI

选择 Pydantic AI 作为基础框架的理由：

| 维度 | 说明 |
|------|------|
| **Capability 机制** | 官方提供的插件抽象，支持运行时动态组装 |
| **类型安全** | 基于 Pydantic v2，编译时类型检查 |
| **模型无关** | 支持 OpenAI、Anthropic、Gemini 等多种模型 |
| **工具系统** | 灵活的工具注册和调用机制 |

### 2.2 关键技术点

| 组件 | 技术方案 | 用途 |
|------|---------|------|
| **动态加载** | `AbstractCapability.get_wrapper_toolset` | 每次运行时动态构建工具集 |
| **技能解析** | 正则 + Frontmatter 解析 | 解析 Markdown 技能的元数据和正文 |
| **触发匹配** | 关键词匹配（可升级为向量检索） | 根据用户输入自动激活相关技能 |
| **上下文传递** | `RunContext.deps` | 在 Agent 运行过程中传递状态 |

### 3.2 数据流

```
1. 用户输入
      │
      ▼
2. Agent 运行，调用 DynamicSkillCapability.get_wrapper_toolset()
      │
      ▼
3. 触发词匹配，将相关技能元数据注入 deps
      │
      ▼
4. Agent 决定是否需要调用 query_skill 工具
      │
      ▼
5. query_skill 读取对应的 .md 文件，返回完整指令
      │
      ▼
6. Agent 依据指令执行任务
```

## 四、核心模块设计

### 4.1 数据结构

```python
@dataclass
class Skill:
    """技能实体"""
    name: str                    # 技能名称（文件名）
    description: str             # 简短描述（用于列表展示）
    instructions: str            # 完整指令正文
    examples: List[str]          # 使用示例（可选）
    triggers: List[str]          # 触发关键词（可选）
    metadata: Dict[str, Any]     # 扩展元数据（如作者、版本、权限）
```

### 4.2 SkillLoader — 技能加载器

**职责：**
- 扫描 `skills/` 目录下的所有 `.md` 文件
- 解析 Frontmatter 元数据（YAML 格式）
- 提取技能正文和示例
- 提供按名称查询、按触发词匹配的能力

**核心方法：**

| 方法 | 说明 |
|------|------|
| `load_all_skills()` | 加载所有技能到内存缓存 |
| `get_skill(name)` | 根据名称获取技能详情 |
| `search_by_trigger(input)` | 根据用户输入匹配触发词 |
| `get_skills_summary()` | 获取所有技能的摘要（供 Agent 预览） |

**文件格式示例：**

```markdown
---
description: 提供数据分析完整能力
triggers: 分析, 统计, 图表
author: data-team
version: 1.0
---

# 技能正文

## 指令
详细的操作步骤...

## 示例
使用案例...
```

### 4.3 DynamicSkillCapability — 动态技能能力

**职责：**
- 作为 Pydantic AI Capability 的桥接层
- 在每次运行时动态组装工具集
- 管理技能相关工具的注册

**核心实现：**

```python
class DynamicSkillCapability(AbstractCapability):
    def get_wrapper_toolset(self, ctx: RunContext) -> Optional[Toolset]:
        """每次运行时调用，动态构建工具集"""
        toolset = Toolset()
        
        # 注册两个核心工具
        toolset.add_tool(QuerySkillTool(self.skill_loader))
        toolset.add_tool(ListSkillsTool(self.skill_loader))
        
        # 触发词匹配，自动激活相关技能
        if ctx.deps.get("user_message"):
            matched = self.skill_loader.search_by_trigger(
                ctx.deps["user_message"]
            )
            ctx.deps["_activated_skills"] = matched
        
        return toolset
```

### 4.4 Agent 工厂函数

```python
def create_skill_agent(skills_dir: str = "./skills") -> Agent:
    """创建支持动态技能加载的 Agent"""
    
    agent = Agent(
        model="openai:gpt-4o",
        deps_type=dict,
        capabilities=[DynamicSkillCapability(skills_dir)],
        system_prompt="""
你是一个使用技能包的专业助手。

工作流程：
1. 判断任务是否需要特定技能
2. 使用 list_skills 查看可用技能
3. 使用 query_skill 获取完整指令
4. 严格遵循指令执行
""",
        model_settings={"temperature": 0.3}
    )
    
    return agent
```

### 6.2 技能权限控制

```python
@dataclass
class Skill:
    # ... 原有字段 ...
    required_roles: List[str] = field(default_factory=list)  # ["admin", "premium"]
    
class PermissiveSkillLoader(SkillLoader):
    def get_skills_for_user(self, user_roles: List[str]) -> List[Skill]:
        """根据用户角色过滤技能"""
        return [
            s for s in self._skills_cache.values()
            if not s.required_roles or any(r in user_roles for r in s.required_roles)
        ]
```

## 八、API 接口设计

### 8.1 Agent 调用接口

```python
# 同步调用
async def chat(user_message: str, user_id: str = None) -> str:
    agent = create_skill_agent()
    deps = {
        "user_message": user_message,
        "user_id": user_id,
        "user_roles": get_user_roles(user_id)  # 权限控制

    result = await agent.run(user_message, deps=deps)
```

## 十、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 技能文件过大 | 占用上下文 | 按需加载 + 分块检索 |
| 技能内容过时 | 执行错误 | 版本控制 + 热加载 |
| 触发词误匹配 | 激活无关技能 | 要求 Agent 确认 + 向量检索 |
| 多技能冲突 | 指令矛盾 | 技能优先级机制 |
| 恶意技能注入 | 安全风险 | 沙箱执行 + 权限审核 |
