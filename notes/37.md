## 第二周：线性方程组、行列式与逆矩阵

> **对应诊断**：题3 ❌ → 题4 ✅ → 题5 ❌ → 题6 ❌

### Day 1-3：高斯消元法（从零搞懂）

| 要搞懂的事 | 为什么对 ML 重要 |
|---|---|
| 增广矩阵 → 行阶梯形 → 行最简形 | 求解线性回归解析解的基础 |
| 主元、自由变量 | 理解方程组何时有唯一解 |
| 消元 = LU 分解的前半段 | LU 是矩阵分解的入门 |

**编程实践：**
```python
from scipy.linalg import lu

A = np.array([[1, 2, 1],
              [2, 5, 3],
              [1, 1, 4]], dtype=float)
b = np.array([4, 9, 5], dtype=float)

# LU 分解看消元过程
P, L, U = lu(A)
print("L:\n", L)  # 消元乘数
print("U:\n", U)  # 上三角结果

# 直接求解
x = np.linalg.solve(A, b)
print("解:", x)
```

## 第三周：特征值与奇异值分解（ML 的灵魂）

> **对应诊断**：题7 ❌ → 题10 ❌

### Day 1-3：特征值与特征向量

| 要搞懂的事 | 为什么对 ML 重要 |
|---|---|
| $A\mathbf{v} = \lambda\mathbf{v}$ 的几何意义 | 方差最大方向 = 第一特征向量 |
| 特征多项式、特征空间 | PCA 的数学基础 |
| 对角化 $A = PDP^{-1}$ | 理解矩阵幂、马尔可夫链稳态 |

**编程实践：**
```python
A = np.array([[3, 1], [0, 2]])
eigvals, eigvecs = np.linalg.eig(A)
print("特征值:", eigvals)
print("特征向量:\n", eigvecs)
# 验证: A @ v = λv
for i in range(2):
    print(f"验证 {i}:", A @ eigvecs[:, i], "==", eigvals[i] * eigvecs[:, i])
```

### Day 4-5：SVD 奇异值分解（重中之重）

| 要搞懂的事 | 为什么对 ML 重要 |
|---|---|
| $A = U\Sigma V^T$ 每部分的含义 | 推荐系统、降维、图像压缩的核心 |
| 奇异值 vs 特征值 | 任何矩阵都能 SVD，不限于方阵 |
| 低秩近似 | 理解矩阵压缩、LoRA（大模型微调）的本质 |

**编程实践：**
```python
# 用 SVD 做图像压缩
from PIL import Image
img = np.array(Image.open('some_image.jpg').convert('L'), dtype=float)
U, S, Vt = np.linalg.svd(img, full_matrices=False)

# 只用前 k 个奇异值重建
k = 20
compressed = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
compression_ratio = (img.size) / (k * (U.shape[0] + Vt.shape[0] + 1))
print(f"压缩比: {compression_ratio:.1f}x")
```

## 第四周：实战整合 — 用线性代数理解 ML 算法

### Day 1-3：PCA 从零实现

```python
import numpy as np

def pca_from_scratch(X, n_components=2):
    """手动实现 PCA，不调 sklearn"""
    # 1. 中心化
    X_centered = X - X.mean(axis=0)
    # 2. 协方差矩阵
    cov = X_centered.T @ X_centered / (X.shape[0] - 1)
    # 3. 特征分解
    eigvals, eigvecs = np.linalg.eigh(cov)
    # 4. 取最大的 n_components 个特征向量
    idx = np.argsort(eigvals)[::-1]
    W = eigvecs[:, idx[:n_components]]
    # 5. 投影
    return X_centered @ W
```
