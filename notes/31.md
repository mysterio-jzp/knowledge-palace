# 世界模型（World Model）

## 一句话定义

> **让 AI 在行动前能预测后果、在"脑中"模拟"如果……会怎样"的系统。** 任何世界模型都只是对世界的"表征"，不等同于世界本身。

世界模型目前**没有统一的公认定义**。2024 年后多篇综述公认该用法"混乱"和"碎片化"。四个流派在用四种不同的方式做四件不同的事，衡量标准各不相同。

---

## 一、概念的历史沿革

### 1.1 1943 年：心理学雏形

英国心理学家 Kenneth Craik 在《解释的本质》（_The Nature of Explanation_）中提出：大脑携带着"**外部现实的小尺度模型**"（small-scale model of external reality），生物体用它来试验各种选择、预测后果、做出反应。这是概念最早的心理/认知科学源头，几乎所有世界模型论文都会引用。

### 1.2 1960 年代：符号 AI —— 积木世界

Terry Winograd 1972 年在 MIT 完成 **SHRDLU** 系统——在一个严格限定的"积木世界"中用**手工编码的符号系统**理解自然语言指令、规划动作。局限：完全依赖人工规则，无法扩展到真实世界，是导致 AI 寒冬的原因之一。

### 1.3 1990 年：深度学习入场

**Jürgen Schmidhuber** 发表论文《Making the World Differentiable》，首次提出用**神经网络学习环境的动力学模型**，让 Agent 在学到的模型里"想象"未来。这是世界模型进入机器学习的起点。当时算法和算力都不足，未大规模落地。

### 1.4 2018 年：当代引爆点

**David Ha（Google Brain）与 Jürgen Schmidhuber** 发表论文《World Models》（[arXiv:1803.10122](https://arxiv.org/abs/1803.10122)）：

- 用 **VAE** 将视觉输入压缩为低维向量
- 用 **RNN** 预测下一帧向量和奖励
- Agent 在这个压缩的"梦境"里训练
- 在赛车游戏（CarRacing-v0）和 VizDoom 中验证

**核心意义**：证明了完全在模型内"做梦"训练出的 Agent 在真实环境中也能表现良好。这是当代所有世界模型研究的直接源头。

### 1.5 2018–2023：沉寂期 & 2024 后集中爆发

2018 年恰逢 LLM 路线爆发（GPT-1、BERT），世界模型仅在强化学习小圈子发展（DreamerV1/V2）。

**2024 年后的爆发事件**：

| 时间 | 事件 |
|------|------|
| 2024.02 | OpenAI 发布 Sora，定位"世界模拟器" |
| 2024.02 | Meta 发布 V-JEPA（杨立昆路线首次大规模实现） |
| 2024.02 | Google DeepMind 发布 Genie 1 |
| 2024 | 李飞飞创办 World Labs |
| 2025.01 | NVIDIA 发布 Cosmos（CES） |
| 2025.06 | Meta 发布 IntPhys 2 物理基准 |

| 2026.03 | AMI Labs 完成 10.3 亿美元种子轮 |

| 2026.03 | OpenAI 宣布关闭 Sora |

## 二、四大流派

世界模型目前分成**两大阵营、四个流派**。同一阵营内共享部分思路，但优化目标不同，**不可直接横向比较**。

### 阵营一：为了行动的模型（给 Agent 内部用）

#### 2.1 决策规划派（基于模型的强化学习）

| 维度 | 详情 |
|------|------|
| **核心思路** | 先学环境动力学模型，Agent 在模型内"想象"未来轨迹并试错，再决定真实动作。本质是把昂贵的真实交互搬进"脑内模拟"，提高样本效率 |
| **技术做法** | 感官输入 → 编码为紧凑隐状态 → 预测下一步隐状态和奖励 → 策略在想象序列里训练 |
| **标杆模型** | **DreamerV3**（Hafner et al., 2023，2025 登 _Nature_） |
| **核心成就** | 单套超参数跨 150+ 任务通用；**第一个无需人类示范在 Minecraft 挖到钻石的 RL 算法** |
| **衡量标准** | 规划成功率、任务完成率、样本效率（不要求画面逼真或物理严格正确） |
| **局限** | 结构化环境效果好，开放世界、长程任务、真实物理场景仍吃力 |

#### 2.2 抽象推演派（JEPA / 联合嵌入预测）

| 维度 | 详情 |
|------|------|
| **核心思路** | 在**抽象表征空间**预测"状态会怎么演化"，跳过像素层面的画面生成。强调抓住因果与结构，忽略无关视觉细节 |
| **技术做法** | **JEPA 架构**：对输入编码 → 在表征空间做带掩码的预测（mask + predict）→ 完全不做像素重建 |
| **代表人物** | **杨立昆（Yann LeCun）**，从 2022 年起公开主张"LLM 是死路" |
| **代表模型** | Meta 的 V-JEPA、V-JEPA 2 |
| **商业化** | 2025.11 离开 Meta 创办 **AMI Labs**（2026.03 获 10.3 亿美元种子轮） |
| **衡量标准** | 因果一致性、下游任务表现。**明确反对"靠生成逼真画面来理解世界"** |

### 阵营二：为了呈现的模型（产出给人看/用的世界）

#### 2.3 视频生成派（生成式"世界模拟器"）

| 维度 | 详情 |
|------|------|
| **核心思路** | 训练模型生成视觉逼真且符合物理的视频，把"能生成连贯世界的视频模型"视为世界模拟器 |
| **技术做法** | 扩散模型/自回归模型，预测像素/帧，从海量视频训练 |
| **代表模型** | OpenAI Sora（DiT）、NVIDIA Cosmos、Google Genie、Veo、阿里 Wan、快手可灵 |
| **关键事件** | Sora 2024.02 公布→2026.03 关闭（用户峰值 100 万，月营收最高仅 54 万美元，日烧 100 万美元） |
| **衡量标准** | 视频观感、物理合理性（**争议最集中**：物理基准测试接近随机水平） |

#### 2.4 空间智能派（3D 世界重建与生成）

| 维度 | 详情 |
|------|------|
| **核心思路** | 世界本质是三维的，AI 应直接感知、生成、并与 3D 场景交互，不应停留在二维视频 |
| **代表人物** | **李飞飞（Fei-Fei Li）**，Stanford AI 实验室前主任、ImageNet 之母 |
| **技术做法** | 文本/图像/视频 → **Gaussian Splatting** + Diffusion → 持久 3D 环境 |
| **产品** | **Marble**（2025.11 发布）：输入文本/图像/视频 → 生成完整 3D 世界，可下载、编辑、导出为 Gaussian splats / mesh / 视频 |
| **融资** | 累计 12.3 亿美元（种子轮 2.3 亿 + B 轮 10 亿） |
| **衡量标准** | 3D 重建/生成的保真度、可交互性 |

### 四派对比总览

| 流派 | 优化目标 | 衡量标准 | 产出形式 | 代表 |
|------|---------|---------|---------|------|
| 决策规划派 | 样本高效的决策 | 规划/任务成功率 | 内部隐状态 | DreamerV3 |
| 抽象推演派 | 因果一致的预测 | 因果一致性 | 抽象表征 | V-JEPA / AMI Labs |
| 视频生成派 | 视觉逼真的视频 | 视频观感 | 2D 视频 | Sora / Cosmos / Genie |
| 空间智能派 | 可交互的 3D 世界 | 3D 保真度 | 3D 场景 | World Labs Marble |

> **类比**：四派不可直接比较，就像让 Dreamer 跟 Sora 比是"鸡同鸭讲"。

## 三、技术架构

### 3.1 形式化定义

世界模型可形式化为函数映射系统：

$$
s_{t+1} = f(s_t, a_t) + \epsilon_t
$$

- $s_t$：时间步 $t$ 的环境状态
- $a_t$：智能体在该时刻的动作
- $f$：环境状态转移函数
- $\epsilon_t$：随机噪声

对于高维观测 $o_t$（如图像），通过编码器映射到潜在空间：

$$
z_t = e_\phi(o_t)
$$

然后在潜在空间中进行状态转移预测：

$$
z_{t+1} = f_\theta(z_t, a_t)
$$

训练目标通常包括重构误差与未来状态预测误差：

$$
\mathcal{L} = \mathcal{L}_{\text{recon}}(o_t, d_\psi(z_t)) + \lambda \cdot \mathcal{L}_{\text{pred}}(z_{t+1}, f_\theta(z_t, a_t))
$$

### 3.2 当前主流架构：工程拼接

**目前没有像 Transformer 之于 LLM 那样统一的架构。** 各派架构是不同的组件拼接：

| 模型 | 架构组件来源 |
|------|------------|
| DreamerV3 | VAE + RNN + Actor-Critic RL + Imagined Rollouts |
| JEPA | Encoder + Predictor + Mask 训练 + 防表征塌缩技巧（VICReg、EMA 等） |
| Sora（DiT） | Diffusion + Transformer + Patches |
| Marble | Gaussian Splatting + Diffusion + 3D 表征 |

### 3.3 方法论主轴分歧

- **生成像素派**（观测空间预测）：直接预测像素/帧。优点：输出可见、可解释；缺点：大量算力花在无关视觉细节上，物理一致性难以保证
- **抽象表征派**（隐空间预测）：不重建画面，只预测抽象状态演化。优点：高效、聚焦结构；缺点：难诊断、有"表征塌缩"风险

### 3.4 类比：与 Transformer 发展史对比

- Transformer 2017 年提出后，经历了 Encoder（BERT）、Decoder（GPT）、Encoder-Decoder（T5）约 **5 年混战**，最终收敛到 Decoder-only
- 世界模型目前仍处于类似 2014–2017 NLP 圈的"百家争鸣"阶段，**还没有哪个架构被反复验证为通解**
- 即使是杨立昆这样的教父级人物，长期押注的 EBM（能量模型）路线也未成主流，凭直觉押架构未必正确

## 四、核心争议：模型真的"懂"物理吗？

### 4.1 直觉物理基准测试

研究者开发了基于婴儿心理学"违反预期"范式的测试基准，发现**目前所有生成式视频模型在物理理解上接近随机水平**：

| 基准 | 来源 | 核心发现 |
|------|------|---------|
| **IntPhys 2** | Meta 2025.06 | 测试 4 条物理原则（永恒性、不变性、时空连续性、固体性）。**主流视频模型接近 50% 随机水平，人类近乎满分** |
| **Physics-IQ** | DeepMind 2025 | 类似结论：生成视频常违反基本物理规则 |
| **VideoPhy** | UCLA 2024 | 模型抓到的只是"统计上像物理"，不是"真懂物理" |

### 4.2 两派立场

- **杨立昆一派**：将 IntPhys 2 视为"生成式路线的死刑判决"
- **OpenAI 等**：视为"现阶段局限，scale up 能解决"。但随着 Sora 关闭，此立场说服力变弱

### 4.3 表征不是本体

源自康德"物自体"概念：我们认识不了事物本身，只能认识它呈现给感官与理性的那一面。

- Sora 的视频是**视觉表征**
- Dreamer 的隐状态是**压缩表征**
- Marble 的 3D 场景是**几何表征**

**三者都是表征，都不等于世界本身。** 工程标准是"够用"，不是"为真"。

## 五、各派"够用区"与"失败区"

| 流派 | 够用区 | 失败区 |
|------|--------|--------|
| DreamerV3 | Atari、Minecraft、结构化机器人控制 | 开放世界、长程任务、真实物理 |
| Sora | 内容创作、广告、影视可视化 | 物理一致性测试、单位经济（已关闭） |
| Cosmos | 为机器人/自动驾驶生成训练数据 | 尚无公开案例证明比传统方法更强 |
| Marble | 游戏世界、设计可视化、教学仿真 | 发布仅半年，物理交互成熟度待验证 |
| V-JEPA | 因果推理、直觉物理基准 | 视觉质量和工程落地远不如生成式路线 |

## 六、应用场景

1. **机器人和具身智能**：用世界模型生成合成训练数据（Cosmos、Marble 主打）
2. **自动驾驶**：Tesla FSD、Wayve、Comma.ai 做闭环仿真，减少真实路测
3. **游戏和元宇宙**：Marble、Genie 直接产出可玩世界
4. **内容生成**：Sora、Veo、可灵等视频创作（C 端商业模式清晰）
5. **科学仿真**：分子动力学、气候模拟、流体力学（DeepMind GraphCast 为先驱）

### 实时性硬约束

| 场景 | 延迟要求 |
|------|---------|
| 机器人控制 | 毫秒级 |
| 自动驾驶 | 10–100 毫秒级 |
| 游戏渲染 | 16 毫秒（60 帧） |
| **当前主流世界模型** | **几秒到几分钟** |

**离实时差 2–4 个数量级。**

---

## 七、公认的开放问题

1. **统一定义与基准缺失**：四派各说各话，没有像 ImageNet 那样的全行业公认 benchmark
2. **物理一致性**：生成式视频模型在直觉物理基准上接近随机水平
3. **长程一致性与误差累积**：短时预测尚可，时间拉长（几分钟以上）物理一致性崩溃
4. **实时性**：推理速度离实时门槛差 2–4 个数量级
5. **基准打架**：同一模型"看着好不好"满分，"懂不懂物理"不及格。评测体系无共识
6. **泛化能力**：如何让世界模型具备跨任务、跨环境的泛化能力

## 九、总结

> "世界模型"没有统一定义。四派人马用四种不同方式做四件不同的事，衡量标准各不相同，互相不可直接比较。整个领域仍处于早期试错阶段，远未收敛。

下次看到"世界模型"这个词，**第一句话应该问："你说的是哪一派？"**
